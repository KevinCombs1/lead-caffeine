Objective
Add a "Full Enrichment" action on each Portfolio company card that runs the most comprehensive, methodical tax credit analysis possible — one company at a time. Uses every engine, every API, every data source in the system. No web scraping. Methodical pacing with generous delays to eliminate any rate-limiting risk.

After enrichment completes, all data is displayed accurately and visually appealing. A "Summary" button opens a polished, client-ready intelligence brief — no methodology shown, no data source references. Just authoritative, matter-of-fact financial statements connecting the company's own numbers to specific credit eligibility with dollar amounts. Smart, concise, professional.

What Gets Analyzed (Per Company)
SEC EDGAR (4 endpoints): submissions, companyfacts (105 XBRL concepts across 16 categories), 10-K footnote HTML extraction (up to 3 most recent 10-Ks), 8-K material event signal mapping
All 39 Tax Credits: Each analyzed with specialized analyzers (R&D, Foreign, Depreciation, Employment, Energy, Generic), per-credit confidence %, evidence chains, diagnostic notes
43 Fingerprint Rules: BUILT_IN_FINGERPRINTS for heuristic gap detection, cascade/exclusion rule application, priority scoring
Credit Interactions: Mutual exclusion detection (ITC↔PTC), structural limits (GILTI/BEAT), redundancy checks (§179↔Bonus Depreciation), interaction adjustments applied to values
Multi-Year Trends: 3-year time series for 12 financial metrics, credit drop-off detection, R&D growth divergence, NOL accumulation/utilization patterns
Industry Benchmarking: Peer comparison against same 2-digit SIC group, outlier detection for under-utilized credits
10-K Footnote NLP: §382 limitation detection, valuation allowance analysis, credit-specific keyword extraction, carryforward identification
Company-Specific Deal Sources (11 targeted API queries):
USASpending: government contracts by recipient name
USPTO PatentsView: patents by assignee organization
Federal Register: industry-relevant regulations by SIC/NAICS
OpenFEMA: disaster declarations in company's state
openFDA: drug approvals/device clearances if pharma/medical SIC
FDIC: bank financial data if financial SIC
Congress.gov: recent tax legislation relevant to company's industry
FRED: economic indicators relevant to company sector
BLS: industry employment statistics
Census: industry demographics and trade data
Treasury: fiscal policy data
Local Intelligence: Query dealEvents/dealEntities for pre-harvested data matching this company, convergence point analysis for company's sector/geography
Retroactive Recovery: Per-credit 3-year IRS lookback with year-by-year value estimation
Legislative Triggers: Map recent congressional actions to company-specific credit opportunities
Pacing Strategy (Zero Rate-Limit Risk)
10-second minimum between SEC API calls
3-second delays between deal source API calls
Total enrichment time: ~2-4 minutes per company (methodical, not rushed)
One company at a time (global lock, reject if another is running)
Every API call reported to user in real-time via SSE
