Objective
Replace the broken SEC browse-edgar CGI endpoint with a local company index built from SEC's modern APIs. The index downloads the full SEC company dataset with SIC codes, caches it in-memory, and refreshes every 24 hours (only discarding old data once the new download completes). All findCompaniesBySIC callers (gradient sweep, Bloom discovery, prospect discovery, pyramid discovery) become instant local lookups. The /api/light/search endpoint gets enriched with SIC codes for free.

Architecture
Index Build Strategy (two-phase):

Phase 1 — Instant base: Fetch company_tickers.json (~500KB, 10,412 entries with CIK, ticker, name). Available in <1 second.
Phase 2 — SIC enrichment: For each company, fetch submissions/CIK*.json to get SIC code + state. Rate-limited at 8 parallel / 1s delay between batches. ~18 minutes for full build, but the index is usable immediately (entries without SIC are simply skipped in SIC-based queries until enriched).
Refresh cycle:

Every 24 hours, trigger a full rebuild in the background
Old index stays active until new one completes
Atomic swap: newIndex → activeIndex only after 100% enrichment
Pivots enabled by local index:

findCompaniesBySIC → instant local filter (was: broken CGI call)
searchCompanies / /api/light/search → enriched with SIC code, state, industry category (was: no SIC data)
sicCache → eliminated (the full index IS the cache)
loadAllCompanies → merged into the index (no separate ticker data fetch)
Data Shape
CompanyIndexEntry {
  cik: string        // 10-digit zero-padded
  ticker: string     // e.g. "AAPL"
  name: string       // e.g. "Apple Inc."
  sic?: string       // 4-digit SIC code (null until enriched)
  state?: string     // 2-letter state code (null until enriched)
  exchange?: string  // from company_tickers_exchange.json
}

async refresh(): Build a NEW index in parallel. Once complete, atomically swap it in. Called every 24 hours by a setInterval.
findBySIC(sicCodes: string[], maxResults: number): Filter entries by SIC code, return matches. Only returns enriched entries.
search(query: string, maxResults: number): Search by name/ticker (replaces searchCompanies). Includes SIC/state in results.
getStatus(): Returns { total, enriched, building, buildPhase, lastBuilt }
